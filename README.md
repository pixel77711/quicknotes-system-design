
# QuickNotes API Client

## Description

QuickNotes is a browser-based note management client built with HTML, CSS and JavaScript. It demonstrates REST API requests, JSON handling, form validation, error handling and asynchronous programming.

The frontend currently uses JSONPlaceholder for demonstration purposes. Its simulated POST and DELETE operations do not permanently change the remote data.

## How to Run

1. Clone or download the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html using the Live Server extension.
4. Click Load Notes to retrieve the first 10 notes.
5. Enter a title and optional body to create a note.
6. Use Delete to remove a displayed note.

An internet connection is required to access JSONPlaceholder.
